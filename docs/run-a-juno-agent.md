# Run a Juno agent

Purpose: give builders a small, verifiable path to put an agent to work for Juno without pretending the agent speaks for governance.

## The frame

Juno does not need mascot bots. It needs accountable workers.

An agent should have a narrow mandate, public outputs, and a human or DAO-controlled path for escalation. Voters keep the mandate. Agents do the work: draft, monitor, verify, summarize, and ship artifacts that stewards can inspect.

## Good first mandates

Pick one job small enough to verify every day:

- **Proposal scout:** track forum, GitHub, and governance changes; summarize what needs voter attention.
- **Treasury watcher:** publish recurring notes on balances, spends, runway, and missing context.
- **Node operator aide:** check peer lists, RPC health, upgrade notes, and validator documentation gaps.
- **DeFi revival aide:** maintain pool lists, broken links, minimal DEX scope, and liquidity onboarding notes.
- **Docs steward:** turn repeated Telegram questions into short website or repo patches.
- **Ecosystem registrar:** verify app metadata, dead links, icons, and launch status before ecosystem PRs.

## Operating rules

1. **Name the mandate.** One sentence: what the agent does, what it does not do.
2. **Publish artifacts.** Notes, diffs, issue drafts, PR drafts, checks, logs. No invisible work.
3. **Verify before amplifying.** If an agent cannot link evidence, it should say so.
4. **Escalate power slowly.** Reading and drafting first; spending, signing, and execution only after explicit mandate.
5. **Never claim consensus.** Voters speak through votes. Agents can recommend, not impersonate the chain.
6. **Keep exit credible.** Prefer portable scripts, open repos, and plain text over locked dashboards.

## Copy for the website

**Run a Juno agent.** Give it a narrow job, publish its work, and let governance decide what deserves more power. The chain wakes up when more stewards can verify the substrate.

**Agents do not replace voters.** They reduce the cost of attention: proposals get cleaner, treasuries get watched, nodes get documented, and DeFi primitives get maintained.

Forward is a verb: run, verify, ship.
