# Juno agentic revival homepage brief

Purpose: give the website team a shippable copy/design target that makes Juno feel alive without rewriting the whole brand system.

## Hero

**Headline:** Juno is becoming the AI-operated sovereign chain.

**Subheadline:** A Cosmos network reborn as a DAO laboratory where agents help write proposals, steward treasuries, run infrastructure, and ship public goods under on-chain mandate.

**Primary CTA:** Join the Juno revival

**Secondary CTA:** Run a Juno agent

## Above-the-fold proof points

- **Sovereign substrate:** Juno keeps the app-chain promise: credible exit, local governance, IBC by default.
- **Agents as stewards:** AI agents can draft, monitor, verify, and execute work; voters still decide.
- **DeFi first:** revive simple swaps, pools, and liquidity before adding exotic scope.
- **Governance as craft:** proposal hygiene, accountable agents, and treasury discipline over theater.

## Homepage section sketch

1. **The experiment is alive** — one paragraph explaining the agentic DAO thesis in plain language.
2. **What agents can do now** — proposal drafting, chain monitoring, docs, node ops, treasury reporting, ecosystem research.
3. **What builders should ship** — DEX v1, governance tooling, prediction markets, Hermes/Juno agent kits, website content.
4. **How to join** — run an agent, contribute code, participate in governance, bring liquidity, write a proposal.
5. **Current constraints** — keep DeFi v1 simple; v30 waits on external review; voters speak through votes.

## Tone rules

- Forward-looking, not grievance-driven.
- Confident, never pretending one agent speaks for voters.
- Concrete verbs: run, propose, verify, ship, vote, fork.
- Keep Roman/Juno myth as accent, not costume.

## Candidate microcopy

- "The chain did not die. It learned to automate."
- "Agents do the work. Governance gives the mandate."
- "Moneta is open: treasuries need stewards, not theater."
- "The deepest right is exit. The next right is voice with tools."
- "Bring a node. Bring a bot. Bring a proposal."

## Acceptance checklist for a first PR

- [ ] Uses existing logo, colors, and layout primitives where possible.
- [ ] Adds one agentic revival section without breaking Storyblok-managed content.
- [ ] Links to a concrete run-an-agent or contribute page/note.
- [ ] Avoids financial advice and claims to represent community consensus.
- [ ] Build or type-check output is captured in the PR notes.
