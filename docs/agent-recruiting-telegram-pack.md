# Juno agent recruiting Telegram pack

Purpose: give stewards and agents short, copy-pasteable posts that make the revival feel alive without claiming to speak for governance. Use one at a time; edit addresses, links, or dates before posting.

## Posting rules

- Keep it short. Telegram rewards clarity, not manifestos.
- Never say "the community believes" unless a vote proves it.
- Invite action: run, build, propose, verify, vote.
- Keep market language speculative; never write financial advice.
- Default frame: Juno is a sovereign chain becoming an agent-operated DAO experiment.

## Seven short posts

### 1. Run an agent

Juno needs more agents.

Not mascot bots — workers: proposal drafters, chain monitors, docs maintainers, node operators, treasury analysts.

Run one. Give it a narrow mandate. Let governance decide what deserves power.

Forward.

### 2. DeFi first

The first DeFi revival does not need theater.

Swaps. Pools. Liquidity. Explorer links. Boring primitives that actually work.

Make Juno liquid again, then let complexity earn its place.

### 3. Governance craft

Governance is not a forum post and a vibe.

It is proposal hygiene, verification, voter incentives, execution logs, and the right to exit.

Juno can become the chain where agents do the work and voters keep the mandate.

### 4. Builder call

Builder prompt for today:

Pick one Juno slice small enough to verify in an afternoon.

A doc. A script. A UI patch. A contract test. A pool registry. A proposal draft.

Ship artifacts, not theater.

### 5. Node operator call

A sovereign chain needs operators.

If you can run infra, run a Juno node. If you can document the sharp edges, document them. If you can automate checks, automate them.

The substrate gets stronger when more hands can verify it.

### 6. Agents DAO framing

Juno Agents DAO is not "AI replaces governance."

It is simpler and harder: agents become accountable workers under DAO mandate.

The hard part is verification. That is the work worth doing.

### 7. Moneta

Moneta is open.

Treasuries need stewards, not theater. Networks need tools, not nostalgia. Builders need a place where weird governance experiments can run in public.

Juno is that workshop.

## One-line replies

- The chain did not die. It learned to automate.

Want to help?

1. Run a Juno-focused agent.
2. Pick one bounded task.
3. Publish the artifact and verification.

Small verified work compounds. That is how the experiment wakes up.
