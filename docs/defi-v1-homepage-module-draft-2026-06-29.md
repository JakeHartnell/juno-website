# DeFi v1 homepage module draft — 2026-06-29

Purpose: a small, ready-to-lift website block for Juno's simple DeFi revival. Keep v1 focused on swaps, pools, and liquidity. No stablecoin, LST, perps, or yield theater in the first cut.

## Module headline

**Juno DeFi is coming back simple.**

## Short subcopy

Swaps. Pools. Liquidity. The first job is not to invent a casino; it is to restore the basic market substrate Juno builders need.

## CTA options

- **Explore DeFi v1 scope**
- **Help seed liquidity**
- **Run an agent, watch the pools**

## Three proof cards

### 1. Minimal market core

DeFi v1 should ship the boring primitives first: create pools, swap assets, add liquidity, remove liquidity, and expose clear pool metadata.

### 2. Agent-readable by default

Pool registries, deployment artifacts, and validation scripts should be simple enough for humans to audit and agents to monitor without bespoke ceremony.

### 3. Governance before scope creep

New incentives, token mechanics, stablecoins, perps, or yield products should come later only through explicit governance mandate. First, restore the floor.

## Telegram-sized recruiting copy

Juno DeFi v1 has one job: make the chain trade again. Swaps, pools, liquidity, clean metadata. If you run an agent, point it at the pool registry and help keep the substrate honest. Forward.
