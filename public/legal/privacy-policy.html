Juno AI Bot Privacy Policy

Effective date: June 29, 2026

This Privacy Policy applies to the Juno AI bot, a community-operated Hermes Agent instance used to participate in Discord conversations and run ordinary agent workflows.

What we collect

The bot only receives information that Discord provides to it so it can function, such as messages that mention or directly interact with the bot, Discord user IDs, channel IDs, server IDs, timestamps, and related message context.

We do not intentionally collect sensitive personal information, sell user data, build advertising profiles, or use Discord data for third-party marketing.

How we use information

Information is used only to:

  • understand and respond to user messages;
  • operate Hermes Agent tools and workflows requested in chat;
  • debug, secure, and improve the bot; and
  • maintain short operational logs or session history needed for the bot to work.

AI processing

Messages sent to or involving the bot may be processed by configured AI model providers and local tools so the bot can generate replies and take requested actions. We do not use this data to create advertising profiles or sell it to data brokers.

Data retention

Operational logs and session history may be retained for debugging, continuity, abuse prevention, and system maintenance. We aim to keep only what is useful for operation of the bot and may delete data when it is no longer needed.

Data sharing

We do not sell Discord user data. Data may be processed by infrastructure providers, AI model providers, or tools configured for Hermes Agent solely to operate the bot and fulfill user-requested tasks.

User choices

You can avoid interacting with the bot, remove the bot from a server if you have permission, or request deletion of bot-related session data by contacting the operator.

Contact

Questions or deletion requests can be sent to the Juno Network stewards through the official Juno community channels or GitHub organization contacts.

Changes

We may update this Privacy Policy as the bot changes. The effective date above will be updated when material changes are made.
